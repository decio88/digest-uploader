Digest Uploader

Digest Uploader is a personal, single-user tool. Each morning it uploads one file, the owner's daily reading digest (an EPUB e-book), to a folder in the owner's own Google Drive, so that an e-reader can sync it.

It uses the drive.file permission, so it can only see and manage the files it creates itself. It does not read, list or change any other files in the account.
